# Сутрешен вестник

Всяка сутрин програмата сама събира най-важните новини от последните 24 часа, обобщава ги
на български с Claude и прави от тях едностраничен вестник във Word (`.docx`).

Във вестника има:

- **„Денят с 3 изречения“** – целият ден накратко;
- **времето за Пловдив** – прогноза за сутринта, обяд и вечерта, шанс за дъжд, вятър и съвет за деня;
- **„Главното днес“** – 3–5-те най-важни истории;
- **рубрики** – България, Армения, Свят, Технологии и AI, Любопитно;
- **линкове към източниците** под всяка новина.

## Как работи

1. Изтегля новините от RSS източниците в `sources.yaml` (БТА, Дневник, Медиапул, BBC, The Guardian, News.am, Ars Technica).
2. Маха повтарящите се заглавия.
3. Claude обединява еднаквите истории, избира най-важните и пише кратки резюмета.
4. Взима прогнозата за времето от [Open-Meteo](https://open-meteo.com) (безплатно, без ключ).
5. Подрежда всичко в две колони на една A4 страница.

## Нужно е

- macOS
- Python 3.9+
- [Claude Code](https://claude.com/claude-code), инсталиран и влязъл в профила (командата `claude`)

## Инсталиране

```bash
python3 -m venv ../.venv
../.venv/bin/pip install -r requirements.txt
```

## Пускане на ръка

```bash
../.venv/bin/python vestnik.py
```

Готовият вестник се записва на три места:

- `newspapers/ГГГГ-ММ-ДД.docx` – архив с всички броеве;
- `latest.docx` – последният брой;
- `~/Desktop/Сутрешен вестник.docx` – за бърз достъп.

Ако искаш да смениш само оформлението, без да теглиш и обобщаваш новините наново:

```bash
../.venv/bin/python vestnik.py --redo
```

## Автоматично всеки ден в 06:00

```bash
./install.sh
```

Ако Mac-ът спи в 06:00, вестникът се прави при събуждане. Ако е бил изключен, се прави при
влизане в профила. Когато е готов, се появява известие. Първия път macOS пита дали
„Сутрешен вестник“ може да ползва папката Desktop – отговори **Allow**.

За спиране на автоматичното пускане:

```bash
./uninstall.sh
```

При проблем виж `logs/vestnik.log`.

## Настройки

Всичко се променя в `sources.yaml`:

- **източници** – добави или махни ред в `sources`;
- **град за времето** – смени `weather` (координатите се намират с десен клик в Google Maps);
- **брой новини, интереси, модел** – в `settings`.
